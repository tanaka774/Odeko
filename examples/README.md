# Examples

| Folder                                                | What's inside                                                         | Start with                       |
| ----------------------------------------------------- | --------------------------------------------------------------------- | -------------------------------- |
| [`presets/`](presets)                                 | Whole canvases to import: feature tours and complete themes           | `Daily Desk.json`                |
| [`custom-css/`](custom-css)                           | One theme per widget type, plus canvas icons                          | the file named after your widget |
| [`custom-html-widgets/`](custom-html-widgets)         | Widgets written as a web page, with saved data and network access     | `command-deck.html`              |
| [`custom-html-backgrounds/`](custom-html-backgrounds) | Backgrounds written as a web page that react to the pointer and icons | `meteor-defense.html`            |
| [`custom-shaders/`](custom-shaders)                   | Animated GLSL backgrounds, Shadertoy style                            | `starter.glsl`                   |

Each folder's README explains how to install its files. To have an AI write
one for you, paste that README into the chat, or ask the AI chat widget,
which reads these examples itself.
