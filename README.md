## What is this

This app is like a floating canvas where you can place icons or widgets on it.  
When launched, it appears on top of your desktop.  
You can set a custom image, URL link, or app launching path on an icon. Widgets are the ones prepared to expect usual daily usage.  
You can use this app as a canvas on the desktop to put or customize everything you need. And with one shortcut key, you can open it anytime.

[odeko-demo.webm](https://github.com/user-attachments/assets/51fe85b2-4242-4d32-a32e-c8a467533c4f)

## Motivation

- Usual background widget or icon system isn't for me, because I always open every app I use and they hide most of the background. It's not a good feeling when my favorite customization is being overridden mercilessly by ADHD-opened browser, terminal, editor or anything else.
- It seems to me the current desktop customization situation is too OS (distro)-dependent. I think cross-platform solution should exist.
- I miss Windows Live Tiles that was a customizable start menu! I heard everyone misses it, right?

## Features

### View Mode and Edit Mode

View Mode is the default state you can interact with things you put. You can enter Edit Mode from the right-click menu or a configured keybind.
You are supposed to change any state of the app in Edit Mode.

### Icon Types

- image icon: you can add one from "Add Image/Link", and set an image or GIF as the thumbnail. Online URLs are supported. Set a URL, and clicking the tile opens it in the browser.
- app icon: you can add one from "Add App" which shows installed apps on your system. You can set an image for the thumbnail here too.
- widget: you can add one from "Add Widget", and choose from the prepared ones. If you need more, check [custom HTML](https://github.com/tanaka774/Odeko/tree/main/examples/custom-html-widgets).

And you can change basic styles of these icons like background color, opacity or corner radius. You can use custom css for more customization — you can check samples(generated by AI) in [custom CSS examples](https://github.com/tanaka774/Odeko/tree/main/examples/custom-css).

### Keybind

- app-level: toggle the app, enter edit mode...
- icon-level: trigger clicking event

### Grid & Snapping

- In edit mode, you can snap an icon onto a grid line to organize its position. You can turn grid-snapping on/off in settings.

### Presets

- You can save the layout as a preset, and import or export it as a JSON file.

### AI Chat

An AI chat widget: a normal chat assistant that can also change the canvas when you ask.

**Setup**

1. Edit Mode → Add Widget → AI Chat.
2. Right-click it → Open Settings… → Providers → + Add, pick a provider and paste your API key.
   - OpenAI, Anthropic, Google Gemini, DeepSeek, OpenRouter, or any OpenAI-compatible server through Custom, including local ones like Ollama and LM Studio (the API key may stay empty).
   - ChatGPT plan: no API key. Press Continue with ChatGPT and sign in in your browser; requests then use your ChatGPT Plus/Pro plan. Manage its usage at chatgpt.com/settings/usage.
3. Save, then pick the provider for this widget in the Chat tab.

**Web search** (Providers tab → Web search)

| Service  | Needs                                                 | Cost                        |
| -------- | ----------------------------------------------------- | --------------------------- |
| Off      | —                                                     | —                           |
| Built-in | an OpenAI, ChatGPT plan, Anthropic or Gemini provider | billed by that provider     |
| DeepSeek | a DeepSeek provider (reuses its key)                  | $0.75 per 1,000 searches    |
| Tavily   | its own key                                           | 1,000 free searches a month |
| Brave    | its own key                                           | free monthly credit         |
| Exa      | its own key                                           | free monthly credit         |
| SearXNG  | the URL of your own server                            | free                        |

The default is DeepSeek when you have a DeepSeek provider, otherwise Off. "Save and test" checks the setup.

**What it can do**

- Chat, read web pages, search the web, and look at images you attach (paste, drag or the image button; needs a model that accepts images).
- Change the canvas: background layers and shaders, colors, widgets and icons, layout, custom CSS and HTML, presets. It asks once per chat before reading the config, because the config holds app paths and memo text. You can switch that to "Always allow" in the Chat tab.
- Every change applies right away and gets a Revert button in the chat. In Edit Mode, Ctrl+Z and Cancel also undo the AI's changes.
- Take a screenshot of the canvas to check its work.

**What needs your approval or is blocked**

- Approval: app icons that launch a program, launch arguments, non-web links, shortcuts, turning off Sleep/Restart/Shutdown confirmations, renaming or deleting presets.
- Blocked: network permissions of Custom HTML widgets, deleting AI chat widgets.

**Privacy**

- API keys and ChatGPT sign-in tokens are stored by the app's backend in `ai-secrets.json` in the config folder, readable only by you. The interface never receives them, and a key is only ever sent to its own provider.
- Conversations are stored in `ai-chats/` in the config folder. Neither keys nor conversations are part of presets or exported files.
- What you type, attached images, and (once you allow it) the parts of the config the AI reads are sent to your AI provider. Search queries go to the search service you picked. Clipboard history, drawings and network permissions are never sent.

Config folder: `~/.config/odeko` on Linux, `~/Library/Application Support/odeko` on macOS, `%APPDATA%\odeko` on Windows.

## Logs

The app always writes a log file, in release builds too, so a problem in an installed build can be diagnosed after the fact. It is capped at 5 MB and rotated to a single file, and stdout is written as well when the app is started from a terminal.

| Platform | Location                                      |
| -------- | --------------------------------------------- |
| Windows  | `%LOCALAPPDATA%\com.odeko.app\logs\odeko.log` |
| macOS    | `~/Library/Logs/com.odeko.app/odeko.log`      |
| Linux    | `~/.local/share/com.odeko.app/logs/odeko.log` |
